Introdução ao Grid

Grid é um sistema de layout bidimensional que organiza elementos com linhas e colunas.

Principais propriedades:

  • display: grid;
  • grid-template-columns
  • grid-template-rows
  • gap
  • grid-column
  • grid-row

Criando um Grid

A propriedade display: grid; ativa o sistema Grid no elemento

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

Aqui os elementos são distribuídos em três colunas e duas linhas.

Definindo as colunas

Com grid-template-columns,podemos definir quantas colunas vão ter e como o espaço será definido.

Coluna 2
Coluna 3
.container {
    display: grid;
    grid-template-columns: 2fr 1fr 1fr;
    gap: 15px;}

A primeira coluna recebe duas frações do espaço e as outras recebem uma fração.

Definindo as linhas

A propriedade grid-template-rowspermite escolher a altura das linhas.

Centralização de Grid

A propriedade place-items: center; centraliza os itens tanto horizontal quanto vertical.

Centro
.container {
display: grid;
place-items: center;}
