\Introdução ao Flexbox

O Flexbox é utilizado para organizar elementos em uma seguinte dimensão: linha ou coluna.

Suas principais propriedades são:

  • display: flex
  • flex-direction
  • justify-content
  • align-items
  • flex-wrap
  • gap

Como criar um Flexbox?

Primeiro utilizamos: display: flex; Os elementos passam a ser organizados em uma linha por padrão

Item 1
Item 2
Item 3
.container { display: flex; justify-content: space-between; }

Outros:

  • center: centraliza os itens;
  • flex-start: alinha no início;
  • flex-end: alinha no final;
  • space-around: distribui espaço ao redor;
  • space-evenly: distribui espaços iguais.

Centralização

Podemos centralizar um elemento horizontal e verticalmente combinando justify-content e align-items.

Centro
.container {
    display: flex;
    justify-content: center;
    align-items: center;
}

Quebra de linha com flex-wrap

Quando os itens não cabem em uma linha, flex-wrap: wrap; permite que eles passem para linhas seguintes.

Item 1
Item 2
Item 3
Item 4
Item 5
.container {
    display: flex;
    flex-wrap: wrap;
    gap: 12px;
}
